# Colloquial Cantonese Course

A comprehensive manual and course designed to take learners from zero to
confident conversational fluency in everyday Cantonese.

## Vision

This course focuses exclusively on **spoken, colloquial Cantonese**—the language
used in daily life with friends and family. We prioritize natural expression,
modern slang, and the essential particles that give Cantonese its unique flavor.

## Goals

- **Zero to Conversational:** No prior knowledge required.
- **Casual & Practical:** Focused on topics like eating out, socializing, and
  daily errands.
- **Interactive Ready:** Content is structured in a machine-readable Markdown
  format to support future interactive features (audio, exercises, etc.).

## Project Structure

- `content/`: Markdown files for each chapter.
- `README.md`: Project overview and standards.
