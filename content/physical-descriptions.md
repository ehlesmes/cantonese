In this chapter, we will learn vocabulary to describe physical appearance and
clothing, and master the critical noun modification particle ge3 in Cantonese.

Let's dive in!

## 1. Vocabulary: Physical Appearance & Clothing

Let's learn some useful vocabulary for describing people and what they wear:

- `靚仔[leng3zai2|handsome boy / plain white rice]` — handsome
- `靚女[leng3neoi5|pretty girl]` — pretty / beautiful
- `高[gou1|tall]` — tall
- `矮[ai2|short (in height)]` — short (in height)
- `戴[daai3|to wear (accessories like glasses, hats, watches)]`
  `眼鏡[ngaan5geng2|glasses]` — wearing glasses
- `衫[saam1|clothes]` — clothes / shirt
- `裙[kwan4|skirt]` — skirt / dress
- `鞋[haai4|shoes]` — shoes

---

## 2. Noun Modification & Complex Descriptions: `嘅[ge3|possessive / linking particle]`

The particle `嘅[ge3|possessive / linking particle]` is one of the most
frequently used words in Cantonese. We have already seen it as a possessive
marker (similar to English `'s`). Now, we will see how it works as a **general
noun modifier** and a **relative clause linker**.

### 1. Linking Adjectives to Nouns

When you want to describe a noun with a multi-syllable adjective or emphasize an
attribute, you link them using `嘅[ge3|possessive / linking particle]`:

> **Formula:** [Adjective] + `嘅[ge3|possessive / linking particle]` + [Noun]

- `靚[leng3|beautiful]` `嘅[ge3|possessive / linking particle]`
  `衫[saam1|clothes]` — pretty clothes / pretty shirt
- `貴[gwai3|expensive]` `嘅[ge3|possessive / linking particle]`
  `鞋[haai4|shoes]` — expensive shoes
- `平[peng4|cheap]` `嘅[ge3|possessive / linking particle]`
  `電腦[din6nou5|computer]` — cheap computer

_Note_: For simple, single-character adjectives, native speakers often omit
`嘅[ge3|possessive / linking particle]` in fast speech if it forms a common
compound (e.g., linking `大[daai6|big]` and `衫[saam1|clothes]` directly as a
compound). If you use `嘅[ge3|possessive / linking particle]` with a
single-character adjective, you usually need an intensifier like
`好[hou2|good / very]` or a measure word. For example, `大[daai6|big]`
`嘅[ge3|possessive / linking particle]` `衫[saam1|clothes]` sounds unnatural,
whereas `好[hou2|good / very]` `大[daai6|big]`
`嘅[ge3|possessive / linking particle]` `衫[saam1|clothes]` or just
`大[daai6|big]` `衫[saam1|clothes]` sounds natural.

### 2. Linking Phrases & Relative Clauses

In English, relative clauses ("the clothes **that I bought**", "the language
**that you speak**") are placed _after_ the noun they modify, using helper words
like "that", "which", or "who".

In Cantonese, the modifying clause is placed **before** the noun and linked by
`嘅[ge3|possessive / linking particle]`:

> **Formula:** [Clause / Action] + `嘅[ge3|possessive / linking particle]` +
> [Noun]

Let's look at how this changes the word order:

```cantonese
我[ngo5|I] 買[maai5|buy] 嘅[ge3|possessive / linking particle] 衫[saam1|clothes] 呀[aa3|sentence-final particle softening statements, making questions friendly]。
===
The clothes that I bought.
```

```cantonese
我[ngo5|I] 尋日[cam4jat6|yesterday] 喺[hai2|at / in / on] 香港[hoeng1gong2|Hong Kong] 買[maai5|buy] 嘅[ge3|possessive / linking particle] 衫[saam1|clothes] 呀[aa3|sentence-final particle softening statements, making questions friendly]。
===
The clothes that I bought in Hong Kong yesterday.
```

```cantonese
你[nei5|you] 講[gong2|to speak] 嘅[ge3|possessive / linking particle] 廣東話[gwong2dung1waa2|Cantonese language] 好[hou2|good / very] 靚[leng3|beautiful] 呀[aa3|sentence-final particle softening statements, making questions friendly]！
===
The Cantonese that you speak is very beautiful!
```

```cantonese
佢哋[keoi5dei6|they] 食[sik6|to eat] 咗[zo2|completed action marker] 嘅[ge3|possessive / linking particle] 點心[dim2sam1|dim sum] 貴[gwai3|expensive] 囉[lo1|sentence-final particle for obviousness]！
===
The dim sum they ate was expensive, obviously!
```

## 3. Conversational Dialogue

Below is a simple dialogue using appearance descriptors and the ge3 linker
particle.

```dialog
A: 唔該[m4goi1|thank you / please]，你[nei5|you] 睇[tai2|to look / watch] 吓[haa5|brief action marker]！ 嗰[go2|that] 個[go3|general classifier] 戴[daai3|to wear (accessories like glasses, hats, watches)] 眼鏡[ngaan5geng2|glasses] 嘅[ge3|possessive / linking particle] 男仔[naam4zai2|boy] 係[hai6|to be / yes] 邊個[bin1go3|who / which] 呀[aa3|sentence-final particle softening statements, making questions friendly]？
   === Excuse me, take a look! Who is that boy wearing glasses?
B: 佢[keoi5|he / she / it] 係[hai6|to be / yes] 我[ngo5|I] 嘅[ge3|possessive / linking particle] 朋友[pang4jau5|friend] 呀[aa3|sentence-final particle softening statements, making questions friendly]。 佢[keoi5|he / she / it] 著[zoek3|to wear] 緊[gan2|continuous aspect marker] 藍色[laam4sik1|blue color] 嘅[ge3|possessive / linking particle] 衫[saam1|clothes] 呀[aa3|sentence-final particle softening statements, making questions friendly]。
   === He is my friend. He is wearing a blue shirt.
A: 佢[keoi5|he / she / it] 好[hou2|good / very] 靚仔[leng3zai2|handsome boy / plain white rice] 呀[aa3|sentence-final particle softening statements, making questions friendly]！ 隔籬[gaak3lei4|next to] 嗰[go2|that] 個[go3|general classifier] 著[zoek3|to wear] 裙[kwan4|skirt] 嘅[ge3|possessive / linking particle] 靚女[leng3neoi5|pretty girl] 都[dou1|also / all] 係[hai6|to be / yes] 你[nei5|you] 嘅[ge3|possessive / linking particle] 朋友[pang4jau5|friend] 呀[aa3|sentence-final particle softening statements, making questions friendly]？
   === He is very handsome! Is that pretty girl next to him wearing a dress also your friend?
B: 係[hai6|to be / yes] 呀[aa3|sentence-final particle softening statements, making questions friendly]！
   === Yes!
```

## 4. Exercises

Review appearance adjectives and noun modification in Cantonese:

```exercise
question: |
  Translate the following phrase into Cantonese using correct semantic annotations:
  "The clothes that I bought"
answer: 我[ngo5|I] 買[maai5|buy] 嘅[ge3|possessive / linking particle] 衫[saam1|clothes]
explanation: In Cantonese, relative clauses place the modifying action before the noun, linked by the particle 嘅[ge3|possessive / linking particle]. 我[ngo5|I] is "I", 買[maai5|buy] is "to buy", and 衫[saam1|clothes] is "clothes".
```

```exercise
question: |
  Fill in the blank to say "expensive shoes":
  貴[gwai3|expensive] ________ 鞋[haai4|shoes]
answer: 嘅[ge3|possessive / linking particle]
explanation: The particle 嘅[ge3|possessive / linking particle] functions as a general noun modifier to link an adjective to a noun.
```
