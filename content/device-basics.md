## 1. Internet & Device Basics

To describe daily web browsing and computer situations, spoken Cantonese uses:

- `上網[soeng5mong5|to go online / surf the internet]`: To go online or surf the
  web.
- `網上[mong5soeng6|online]`: Adjective/adverb describing online operations or
  sites.
- `下載[haa6zoi3|to download]`: To download files or software.
- `智能電話[zi3nang4 din6waa2|smartphone]`: A smartphone.
- `智能[zi3nang4|smart / intelligent (tech)]`: Smart.
- `WiFi[wai1faai1|Wi-Fi / wireless internet]`: Wi-Fi.
- `網絡[mong5lok3|internet / network]`: Internet connection or network.
- `網[mong5|internet / net / network]`: Internet.
- `死機[sei2gei1|device freeze / crash]`: Device crash or freeze (literally
  "dead machine").

## 2. Situational Dialogue: Wi-Fi Issues

Two friends discuss connectivity issues in a cafe.

```dialog
A: 你[nei5|you] 喺度[hai2dou6|here / in the middle of doing something] 做[zou6|to do / make / perform] 緊[gan2|verbal aspect suffix indicating an action in progress (continuous aspect)] 咩嘢[me1je5|what / what kind of] 呀[aa3|sentence-final particle softening statements, making questions friendly]？
   === What are you doing here?
B: 我[ngo5|I / me] 想[soeng2|to want to / would like to] 上網[soeng5mong5|to go online / surf the internet] 下載[haa6zoi3|to download] 嘢[je5|thing / stuff]，但係[daan6hai6|but] 呢度[ni1dou6|here] 嘅[ge3|possessive or linking particle] WiFi[wai1faai1|Wi-Fi / wireless internet] 網絡[mong5lok3|internet / network] 好[hou2|very] 慢[maan6|slow] 呀[aa3|sentence-final particle softening statements, making questions friendly]。
   === I want to go online to download something, but the Wi-Fi network here is very slow.
A: 係呀[hai6aa3|yes]，我[ngo5|I / me] 嘅[ge3|possessive or linking particle] 智能電話[zi3nang4 din6waa2|smartphone] 都[dou1|also / even / already] 連[lin4|to connect / link] 唔到[m4dou2|cannot / unable to manage to / fail to] 網[mong5|internet / net / network]，頭先[tau4sin1|just now / a moment ago] 仲[zung6|still / also / even more] 死機[sei2gei1|device freeze / crash] 添[tim1|as well / also / particle]！
   === Yes, my smartphone also cannot connect to the internet, it even froze just now!
B: 哇[waa1|wow / whoa]，噉[gam2|then / in that case / so] 真係[zan1hai6|really / truly] 麻煩[maa4faan4|troublesome / bothersome] 喇[laa3|sentence-final particle indicating a change of state or already]！
   === Wow, then that is really troublesome!
```

## 3. Exercises

Test your understanding of internet and device basics in Cantonese.

```exercise
question: |
  Translate the following sentence into colloquial Cantonese:
  "I want to go online to download that app."
answer: 我[ngo5|I / me] 想[soeng2|to want to / would like to / think] 上網[soeng5mong5|to go online / surf the internet] 下載[haa6zoi3|to download] 嗰個[go2go3|that one] App[ep1|mobile application / app]。
explanation: |
  `我[ngo5|I / me]` is "I", `想[soeng2|to want to]` is "want to", `上網[soeng5mong5|to go online]` is "go online", `下載[haa6zoi3|to download]` is "to download", and `嗰個[go2go3|that] App[ep1|app]` is "that app".
```

```exercise
question: |
  Which Cantonese phrase literally meaning "dead machine" is used when a device freezes or crashes?
  A) 爆數據[baau3 sou3geoi3|exceed data limit]
  B) 聲控[sing1hung3|voice control]
  C) 死機[sei2gei1|device crash]
  D) 開關[hoi1gwaan1|switch]
answer: C
explanation: |
  `死機[sei2gei1|device crash]` (literally "dead machine") is the standard colloquial term for a frozen or crashed device.
```
