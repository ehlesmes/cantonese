In this chapter, we will learn how to make comparisons in Cantonese, including
relative comparisons, direct comparisons, equality and negated structures, and
superlatives.

Let's dive in!

---

## 1. The Comparative Suffix: `啲[di1|a bit / some]`

To express that something is "more" [adjective], or has the suffix "-er" (e.g.,
"cheaper", "taller", "bigger"), spoken Cantonese attaches `啲[di1|a bit / some]`
directly after the adjective.

> **Formula:** [Adjective] + `啲[di1|a bit / some]`

- `平[peng4|cheap]` `啲[di1|a bit / some]` — cheaper / a bit cheaper
- `高[gou1|tall]` `啲[di1|a bit / some]` — taller / a bit taller
- `矮[aai2|short (in height)]` `啲[di1|a bit / some]` — shorter / a bit shorter
- `大[daai6|big]` `啲[di1|a bit / some]` — bigger / a bit bigger
- `快[faai3|fast]` `啲[di1|a bit / some]` — faster / a bit faster
- `慢[maan6|slow]` `啲[di1|a bit / some]` — slower / a bit slower

You can use this structure to make requests or describe changes without
comparing two specific things:

```cantonese
唔該[m4goi1|thank you / please] 平[peng4|cheap] 啲[di1|a bit / some] 啦[laa1|sentence-final particle suggesting, requesting, or encouraging action]！
===
Please make it a bit cheaper!
```

```cantonese
行[hang4|to walk] 快[faai3|fast] 啲[di1|a bit / some] 啦[laa1|sentence-final particle suggesting, requesting, or encouraging action]！
===
Walk a bit faster!
```

## 2. Direct Comparisons: `過[gwo3|past experience marker / to cross / than]`

When you want to compare two objects directly (e.g., "A is more [adjective] than
B"), Cantonese uses `過[gwo3|past experience marker / to cross / than]` as the
comparison marker.

_(Note: In comparative structures, it functions as the word "than".)_

### The Basic Comparative Structure

The word order is:

> **Formula:** [Subject A] + [Adjective] +
> `過[gwo3|past experience marker / to cross / than]` + [Subject B]

Notice that we do **not** use `啲[di1|a bit / some]` in this basic direct
structure because `過[gwo3|past experience marker / to cross / than]` already
carries the comparative meaning!

```cantonese
我[ngo5|I] 高[gou1|tall] 過[gwo3|past experience marker / to cross / than] 你[nei5|you] 呀[aa3|sentence-final particle softening statements, making questions friendly]。
===
I am taller than you.
```

```cantonese
呢[ni1|this] 件[gin6|measure word for clothes, matters, and items] 衫[saam1|clothes] 貴[gwai3|expensive] 過[gwo3|past experience marker / to cross / than] 嗰[go2|that] 件[gin6|measure word for clothes, matters, and items] 囉[lo1|sentence-final particle for obviousness]！
===
This shirt is more expensive than that one, obviously!
```

```cantonese
講[gong2|to speak] 廣東話[gwong2dung1waa2|Cantonese language] 難[naan4|difficult] 過[gwo3|past experience marker / to cross / than] 講[gong2|to speak] 英文[jing1man2|English language] 呀[aa3|sentence-final particle softening statements, making questions friendly]。
===
Speaking Cantonese is more difficult than speaking English.
```

### Specifying the Amount of Difference

To specify _how much_ one thing is more than another in a direct comparison,
place the exact amount or a phrase like `好多[hou2do1|a lot of]` **after the
object of comparison**:

> **Formula:** [Subject A] + [Adjective] +
> `過[gwo3|past experience marker / to cross / than]` + [Subject B] + [Amount]

```cantonese
佢[keoi5|he / she / it] 高[gou1|tall] 過[gwo3|past experience marker / to cross / than] 我[ngo5|I] 好多[hou2do1|a lot of] 呀[aa3|sentence-final particle softening statements, making questions friendly]。
===
He is a lot taller than me.
```

```cantonese
呢[ni1|this] 件[gin6|measure word for clothes, matters, and items] 衫[saam1|clothes] 貴[gwai3|expensive] 過[gwo3|past experience marker / to cross / than] 嗰[go2|that] 件[gin6|measure word for clothes, matters, and items] 一百[jat1baak3|one hundred] 蚊[man1|dollar] 囉[lo1|sentence-final particle for obviousness]！
===
This shirt is one hundred dollars more expensive than that one, obviously!
```

## 3. Equality & Negated Comparisons: `同[tung4|with / and]` and `冇[mou5|to not have]`

To say two things are identical, or to say one thing is _not_ as [adjective] as
another, we use specific sentence patterns.

### 1. Saying Things Are the Same: `同[tung4|with / and]` ... `一樣[jat1joeng6|same]`

To express that A is the same as B, link them with `同[tung4|with / and]` and
add `一樣[jat1joeng6|same]` at the end:

> **Formula:** [Subject A] + `同[tung4|with / and]` + [Subject B] +
> `一樣[jat1joeng6|same]` + (Adjective)

```cantonese
呢[ni1|this] 對[deoi3|pair (classifier)] 鞋[haai4|shoes] 同[tung4|with / and] 嗰[go2|that] 對[deoi3|pair (classifier)] 一樣[jat1joeng6|same] 靚[leng3|beautiful] 呀[aa3|sentence-final particle softening statements, making questions friendly]。
===
This pair of shoes is just as pretty as that pair.
```

```cantonese
我[ngo5|I] 同[tung4|with / and] 佢[keoi5|he / she / it] 一樣[jat1joeng6|same] 咁[gam3|so / to this degree] 高[gou1|tall] 囉[lo1|sentence-final particle for obviousness]！
===
I am the same height as him, obviously!
```

### 2. Negating Comparisons: `冇[mou5|to not have]` ... `咁[gam3|so / to this degree]`

To say that A is **not as [adjective] as** B, Cantonese uses a structure with
`冇[mou5|to not have]` and `咁[gam3|so / to this degree]`:

> **Formula:** [Subject A] + `冇[mou5|to not have]` + [Subject B] +
> `咁[gam3|so / to this degree]` + [Adjective]

Literally, this reads: "A does not have B's degree of [adjective]."

```cantonese
我[ngo5|I] 冇[mou5|to not have] 你[nei5|you] 咁[gam3|so / to this degree] 高[gou1|tall] 呀[aa3|sentence-final particle softening statements, making questions friendly]。
===
I am not as tall as you.
```

```cantonese
平[peng4|cheap] 嘅[ge3|possessive / linking particle] 衫[saam1|clothes] 冇[mou5|to not have] 貴[gwai3|expensive] 嘅[ge3|possessive / linking particle] 衫[saam1|clothes] 咁[gam3|so / to this degree] 靚[leng3|beautiful] 囉[lo1|sentence-final particle for obviousness]！
===
Cheap clothes are not as pretty as expensive clothes, obviously!
```

## 4. Superlatives: `最[zeoi3|most]`

To express the absolute "most" of a quality (the superlative), place
`最[zeoi3|most]` directly before the adjective.

> **Formula:** `最[zeoi3|most]` + [Adjective]

- `最[zeoi3|most]` `靚[leng3|beautiful]` — prettiest / most beautiful
- `最[zeoi3|most]` `靚仔[leng3zai2|handsome boy / plain white rice]` — most
  handsome
- `最[zeoi3|most]` `平[peng4|cheap]` — cheapest
- `最[zeoi3|most]` `大[daai6|big]` — biggest

Let's look at some examples:

```cantonese
呢[ni1|this] 對[deoi3|pair (classifier)] 鞋[haai4|shoes] 最[zeoi3|most] 平[peng4|cheap] 呀[aa3|sentence-final particle softening statements, making questions friendly]。
===
This pair of shoes is the cheapest.
```

```cantonese
我[ngo5|I] 最[zeoi3|most] 鍾意[zung1ji3|to like] 食[sik6|to eat] 點心[dim2sam1|dim sum] 啦[laa1|sentence-final particle suggesting, requesting, or encouraging action]！
===
I like eating dim sum the most!
```

## 5. Situational Dialogue: People Watching

Wing-kit (A) and Sau-han (B) are people-watching from a cafe in Mong Kok.

```dialog
A: Sau-han，你[nei5|you] 睇[tai2|to look / watch] 吓[haa5|brief action marker]！嗰[go2|that] 個[go3|general classifier] 男仔[naam4zai2|boy] 好[hou2|good / very] 靚仔[leng3zai2|handsome boy / plain white rice] 呀[aa3|sentence-final particle softening statements, making questions friendly]！
   === Sau-han, take a look! That guy is very handsome!
B: 邊[bin1|which] 個[go3|general classifier] 呀[aa3|sentence-final particle softening statements, making questions friendly]？戴[daai3|to wear (accessories like glasses, hats, watches)] 眼鏡[ngaan5geng2|glasses] 嗰[go2|that] 個[go3|general classifier] 呀[aa3|sentence-final particle softening statements, making questions friendly]？
   === Which one? The one wearing glasses?
A: 係[hai6|to be / yes] 呀[aa3|sentence-final particle softening statements, making questions friendly]。佢[keoi5|he / she / it] 高[gou1|tall] 過[gwo3|past experience marker / to cross / than] 你[nei5|you] 好多[hou2do1|a lot of] 囉[lo1|sentence-final particle for obviousness]！
   === He is a lot taller than you, obviously!
B: 喂[wai3|hey! / hello]！我[ngo5|I] 冇[mou5|to not have] 佢[keoi5|he / she / it] 咁[gam3|so / to this degree] 高[gou1|tall]，但係[daan6hai6|but] 我[ngo5|I] 唔[m4|not] 矮[aai2|short (in height)] 呀[aa3|sentence-final particle softening statements, making questions friendly]！同埋[tung4maai4|and] 佢[keoi5|he / she / it] 件[gin6|measure word for clothes, matters, and items] 衫[saam1|clothes] 冇[mou5|to not have] 我[ngo5|I] 件[gin6|measure word for clothes, matters, and items] 衫[saam1|clothes] 咁[gam3|so / to this degree] 靚[leng3|beautiful] 囉[lo1|sentence-final particle for obviousness]！
   === Hey! I am not as tall as him, but I am not short! And his shirt is not as nice as my shirt, obviously!
A: 係[hai6|to be / yes] 啦[laa1|sentence-final particle suggesting, requesting, or encouraging action] 係[hai6|to be / yes] 啦[laa1|sentence-final particle suggesting, requesting, or encouraging action]。你[nei5|you] 最[zeoi3|most] 靚仔[leng3zai2|handsome boy / plain white rice] 啦[laa1|sentence-final particle suggesting, requesting, or encouraging action]！
   === Yeah, yeah. You are the most handsome!
```

## 6. Exercises

Review comparatives and superlatives in Cantonese:

```exercise
question: |
  Which of the following sentences correctly expresses "This shirt is cheaper than that shirt"?
  A) 呢[ni1|this] 件[gin6|measure word for clothes, matters, and items] 衫[saam1|clothes] 平[peng4|cheap] 啲[di1|a bit / some] 嗰[go2|that] 件[gin6|measure word for clothes, matters, and items] 衫[saam1|clothes] 呀[aa3|sentence-final particle softening statements, making questions friendly]。
  B) 呢[ni1|this] 件[gin6|measure word for clothes, matters, and items] 衫[saam1|clothes] 平[peng4|cheap] 過[gwo3|past experience marker / to cross / than] 嗰[go2|that] 件[gin6|measure word for clothes, matters, and items] 衫[saam1|clothes] 呀[aa3|sentence-final particle softening statements, making questions friendly]。
  C) 呢[ni1|this] 件[gin6|measure word for clothes, matters, and items] 衫[saam1|clothes] 同[tung4|with / and] 嗰[go2|that] 件[gin6|measure word for clothes, matters, and items] 衫[saam1|clothes] 一樣[jat1joeng6|same] 平[peng4|cheap] 呀[aa3|sentence-final particle softening statements, making questions friendly]。
answer: B
explanation: Direct comparisons between two items are formed using the marker 過[gwo3|past experience marker / to cross / than] in the structure [Subject A] + [Adjective] + 過[gwo3|past experience marker / to cross / than] + [Subject B]. Option A incorrectly layers 啲[di1|a bit / some] without the comparison preposition. Option C says they are the same price.
```

```exercise
question: |
  Fill in the blanks to say "I am not as tall as you" in Cantonese:
  我[ngo5|I] ________ 你[nei5|you] ________ 高[gou1|tall] 呀[aa3|sentence-final particle softening statements, making questions friendly]。
answer: 冇[mou5|to not have] / 咁[gam3|so / to this degree]
explanation: Negated comparisons ("not as [adjective] as") are expressed using the pattern [A] + 冇[mou5|to not have] + [B] + 咁[gam3|so / to this degree] + [Adjective].
```
