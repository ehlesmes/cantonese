Welcome to Chapter 2! Now that you know how to introduce yourself and strike up
a basic conversation, it is time to venture out into the vibrant streets of Hong
Kong.

In this lesson, we will focus on everyday transactions—specifically inside the
ubiquitous local convenience stores (like 7-Eleven and Circle K). You will learn
how to express wants and needs, ask how much things cost, count spoken dollars
using Cantonese numerals, pay using modern methods, and master the ultimate
local slang: `搞掂[gaau2dim6|done / finished / settled / resolved]`.

---

## 1. Wanting & Needing: `想[soeng2|to want to / would like to / think]` vs `要[jiu3|to want / need / must / demand]`

To request items or express desires, Cantonese uses two main auxiliary verbs.
Understanding the pragmatic difference between them helps you sound polite and
natural:

- `想[soeng2|to want to / would like to / think]`: Equivalent to "would like to"
  or "want to". It is soft, polite, and expresses an internal desire or
  intention.
- `要[jiu3|to want / need / must / demand]`: Equivalent to "need" or a stronger,
  more assertive "want". It implies necessity or an immediate, direct request.

### Basic Sentence Structure

To ask for or request something, place either auxiliary verb directly before the
verb `買[maai5|to buy]` or use `要[jiu3|to want / need / must / demand]`
directly with a noun:

```cantonese
我[ngo5|I / me] 想[soeng2|to want to / would like to / think] 買[maai5|to buy] 嘢飲[je5jam2|drinks / beverages] 呀[aa3|sentence-final particle softening statements, making questions friendly]。
===
I would like to buy some drinks.
```

```cantonese
我[ngo5|I / me] 要[jiu3|to want / need / must / demand] 呢個[ni1go3|this one]。
===
I need this one.
```

> [!TIP] When you are at a counter ordering or buying something, using a
> combination like `我[ngo5|I]` `想[soeng2|to want to / would like to / think]`
> `要[jiu3|to want / need / must / demand]` is an extremely common, polite, and
> natural way to make requests.

## 2. Pointing Things Out & Connecting Items: `呢個[ni1go3|this one]`, `嗰個[go2go3|that one]`, and `同埋[tung4maai4|and / with]`

If you do not know the name of an object in a shop, you can simply point and use
these high-frequency demonstrative pronouns:

- `呢個[ni1go3|this one]`: Used for items close to you.
- `嗰個[go2go3|that one]`: Used for items further away.

To connect two nouns together, like saying "and" in English, use the conjunction
`同埋[tung4maai4|and / with / together with]`.

Observe how these are used to make simple requests:

```cantonese
我[ngo5|I / me] 想[soeng2|to want to / would like to / think] 買[maai5|to buy] 呢個[ni1go3|this one] 呀[aa3|sentence-final particle softening statements, making questions friendly]。
===
I want to buy this one.
```

```cantonese
我[ngo5|I / me] 要[jiu3|to want / need / must / demand] 呢個[ni1go3|this one] 同埋[tung4maai4|and / with / together with] 嗰個[go2go3|that one] 啦[laa1|sentence-final particle suggesting, requesting, or encouraging action]！
===
I will take this one and that one!
```

## 3. Asking for Prices & Counting Dollars

### Asking "How much?"

To ask how much an item costs, we use `幾多[gei2do1|how many / how much]` and
`錢[cin2|money]`. Together, `幾多[gei2do1|how many / how much]` `錢[cin2|money]`
is the standard phrase for "How much is it?":

```cantonese
呢個[ni1go3|this one] 幾多[gei2do1|how many / how much] 錢[cin2|money] 呀[aa3|sentence-final particle softening statements, making questions friendly]？
===
How much is this one?
```

```cantonese
嗰個[go2go3|that one] 幾多[gei2do1|how many / how much] 錢[cin2|money] 呀[aa3|sentence-final particle softening statements, making questions friendly]？
===
How much is that one?
```

### The Spoken Dollar: `蚊[man1|dollar (spoken Cantonese colloquial unit of currency)]`

In formal written Chinese, currency is represented by words like _jyun_ or
_faai_. However, in spoken Cantonese, you **must** use the colloquial classifier
`蚊[man1|dollar (spoken Cantonese colloquial unit of currency)]` to mean
"dollars".

To state a price, use the pattern: **Number +
`蚊[man1|dollar (spoken Cantonese colloquial unit of currency)]`**

### Cantonese Numerals (1 to 10)

Here are the basic numerals you will use to count dollars and specify
quantities:

- `一[jat1|one]`: One
- `二[ji6|two]`: Two (used in compound numbers like twelve or twenty)
- `三[saam1|three]`: Three
- `四[sei3|four]`: Four
- `五[ng5|five]`: Five
- `六[luk6|six]`: Six
- `七[cat1|seven]`: Seven
- `八[baat3|eight]`: Eight
- `九[gau2|nine]`: Nine
- `十[sap6|ten]`: Ten

> [!IMPORTANT] **The `二[ji6|two]` vs
> `兩[loeng5|two / pair (used with classifiers)]` Rule:** When counting items or
> stating prices with a classifier like
> `蚊[man1|dollar (spoken Cantonese colloquial unit of currency)]`, you must use
> `兩[loeng5|two / pair (used with classifiers)]` instead of `二[ji6|two]`.
>
> - **Correct**: `兩[loeng5|two / pair (used with classifiers)]`
>   `蚊[man1|dollar (spoken Cantonese colloquial unit of currency)]`
> - **Incorrect**: `二[ji6|two]`
>   `蚊[man1|dollar (spoken Cantonese colloquial unit of currency)]`

### Combined Prices

You can easily combine tens and units just like in English:

- `十[sap6|ten]` `五[ng5|five]`
  `蚊[man1|dollar (spoken Cantonese colloquial unit of currency)]` = fifteen
  dollars
- `二十[ji6sap6|twenty]` `三[saam1|three]`
  `蚊[man1|dollar (spoken Cantonese colloquial unit of currency)]` =
  twenty-three dollars
- `三十[saam1sap6|thirty]` `二[ji6|two]`
  `蚊[man1|dollar (spoken Cantonese colloquial unit of currency)]` = thirty-two
  dollars

Let's look at examples:

```cantonese
呢個[ni1go3|this one] 四[sei3|four] 蚊[man1|dollar (spoken Cantonese colloquial unit of currency)]。
===
This one is four dollars.
```

```cantonese
嗰個[go2go3|that one] 二十[ji6sap6|twenty] 蚊[man1|dollar (spoken Cantonese colloquial unit of currency)]。
===
That one is twenty dollars.
```

## 4. Authentic Hong Kong Transactions

When buying something at a local store, you will encounter terms for local
payment methods, change, and convenience items.

### Payment Methods: Octopus & Cash

Hong Kong is famous for its contactless smart card, the
`八達通[baat3daat6tung1|Octopus card (Hong Kong contact-less smart card)]`.
Alternatively, you can use `現金[jin6gam1|cash]`.

To ask if a store accepts a payment method, use the verb
`收[sau1|to receive / accept / collect]` in the A-not-A question form
`收唔收[sau1 m4 sau1|do you accept / accept or not (A-not-A question form)]`:

```cantonese
呢度[ni1dou6|here] 收唔收[sau1 m4 sau1|do you accept / accept or not (A-not-A question form)] 八達通[baat3daat6tung1|Octopus card (Hong Kong contact-less smart card)] 呀[aa3|sentence-final particle softening statements, making questions friendly]？
===
Do you accept Octopus card here?
```

```cantonese
我[ngo5|I / me] 冇[mou5|not to have / without / there is not] 現金[jin6gam1|cash] 呀[aa3|sentence-final particle softening statements, making questions friendly]。
===
I don't have cash.
```

### Plastic Bags & Change

At the register, the clerk will often ask if you need a
`膠袋[gaau1doi2|plastic bag]`:

```cantonese
要唔要[jiu3 m4 jiu3|do you want / want or not (A-not-A question form)] 膠袋[gaau1doi2|plastic bag] 呀[aa3|sentence-final particle softening statements, making questions friendly]？
===
Do you want a plastic bag?
```

If you pay with cash, the clerk will use the verb
`找[zaau2|to give change / look for / seek]` to give you change:

```cantonese
找[zaau2|to give change / look for / seek] 十[sap6|ten] 蚊[man1|dollar (spoken Cantonese colloquial unit of currency)]。
===
Here is ten dollars change.
```

## 5. Daily Slang & Loanwords

### The Ultimate Slang: `搞掂[gaau2dim6|done / finished / settled / resolved]`

One of the most essential Cantonese colloquial words is
`搞掂[gaau2dim6|done / finished / settled / resolved]`. It is an incredibly
versatile adjective/expression used to declare that a task is finished, a
problem is solved, or a transaction is successfully completed.

- When you finish paying:
  `搞掂[gaau2dim6|done / finished / settled / resolved]`！ (Done! / All
  settled!)
- When a task is complete:
  `搞掂[gaau2dim6|done / finished / settled / resolved]`
  `啦[laa1|sentence-final particle suggesting, requesting, or encouraging action]`！ (Sorted!)

### English Loanwords

Spoken Cantonese naturally absorbs English words, adapting their pronunciation
to fit Cantonese phonetics. Here are three crucial loanwords:

- `的士[dik1si2|taxi (loanword)]`: Taxi
- `巴士[baa1si2|bus (loanword)]`: Bus
- `飛[fei1|ticket (loanword, e.g., movie ticket, bus ticket)]`: Ticket

```cantonese
我[ngo5|I / me] 想[soeng2|to want to / would like to / think] 買[maai5|to buy] 巴士[baa1si2|bus (loanword)] 飛[fei1|ticket (loanword, e.g., movie ticket, bus ticket)] 呀[aa3|sentence-final particle softening statements, making questions friendly]。
===
I want to buy a bus ticket.
```

```cantonese
呢度[ni1dou6|here] 冇[mou5|not to have / without / there is not] 的士[dik1si2|taxi (loanword)] 呀[aa3|sentence-final particle softening statements, making questions friendly]。
===
There are no taxis here.
```

## 6. Conversational Dialogue

> [!NOTE] **`唔該[m4goi1|thank you]` vs `多謝[do1ze6|thank you]`** Cantonese has
> two distinct ways to say "thank you." Use
> `唔該[m4goi1|excuse me / please / thank you (for service)]` to thank someone
> for a service or help (like a clerk handing you an item). Use
> `多謝[do1ze6|thank you (for a gift, compliment, or hospitality)]` when
> receiving a gift, paying, or in a retail context where the cashier thanks you
> for your business.

Below is a realistic interaction between a customer (A) and a convenience store
clerk (B) in Hong Kong.

```dialog
A: 你好[nei5hou2|hello / hi]呀[aa3|sentence-final particle softening statements, making questions friendly]！ 唔該[m4goi1|excuse me]，我[ngo5|I] 想[soeng2|to want to / would like to / think] 買[maai5|to buy] 呢個[ni1go3|this one] 同埋[tung4maai4|and / with / together with] 嗰個[go2go3|that one]。
   === Hello there! Excuse me, I want to buy this one and that one.
B: 好[hou2|good / fine / very / quite] 呀[aa3|sentence-final particle softening statements, making questions friendly]。 呢個[ni1go3|this one] 係[hai6|to be (am/is/are) / yes] 可樂[ho2lok6|cola / Coke]，嗰個[go2go3|that one] 係[hai6|to be (am/is/are) / yes] 薯片[syu4pin2|potato chips / crisps]。
   === Sure. This one is Coke, that one is potato chips.
A: 幾多[gei2do1|how many / how much] 錢[cin2|money] 呀[aa3|sentence-final particle softening statements, making questions friendly]？
   === How much is it?
B: 三十[saam1sap6|thirty] 蚊[man1|dollar (spoken Cantonese colloquial unit of currency)] 呀[aa3|sentence-final particle softening statements, making questions friendly]。 要唔要[jiu3 m4 jiu3|do you want / want or not (A-not-A question form)] 膠袋[gaau1doi2|plastic bag] 呀[aa3|sentence-final particle softening statements, making questions friendly]？
   === It is thirty dollars. Do you want a plastic bag?
A: 唔[m4|not / no (negative prefix)] 要[jiu3|to want / need / must / demand] 啦[laa1|sentence-final particle suggesting, requesting, or encouraging action]，唔該[m4goi1|excuse me]。 呢度[ni1dou6|here] 收唔收[sau1 m4 sau1|do you accept / accept or not (A-not-A question form)] 八達通[baat3daat6tung1|Octopus card (Hong Kong contact-less smart card)] 呀[aa3|sentence-final particle softening statements, making questions friendly]？
   === No, thank you. Do you accept Octopus card here?
B: 收[sau1|to receive / accept / collect] 呀[aa3|sentence-final particle softening statements, making questions friendly]！ 多謝[do1ze6|thank you (for a gift, compliment, or hospitality)]。
   === Yes, we do! Thank you.
A: 好[hou2|good / fine / very / quite] 呀[aa3|sentence-final particle softening statements, making questions friendly]。
   === Okay.
B: 搞掂[gaau2dim6|done / finished / settled / resolved] 啦[laa1|sentence-final particle suggesting, requesting, or encouraging action]！ 多謝[do1ze6|thank you (for a gift, compliment, or hospitality)]！
   === All done! Thank you!
A: 唔該[m4goi1|excuse me / please / thank you (for service or help)]！ 拜拜[baai1baai3|bye-bye / goodbye (loanword)]！
   === Thanks! Bye-bye!
B: 拜拜[baai1baai3|bye-bye / goodbye (loanword)]！
   === Bye-bye!
```
