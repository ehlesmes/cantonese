## 1. Cause & Effect: `因為[jan1wai6|because]` ... `所以[so2ji5|therefore / so]`

To explain why something happened and what the result was, Cantonese speakers
use the classic pair `因為[jan1wai6|because]` ... `所以[so2ji5|therefore / so]`.
While English speakers rarely use "because" and "so" in the same sentence, in
Cantonese it is extremely common and natural to use both together.

Structure:

- `因為[jan1wai6|because]` [Cause], `所以[so2ji5|therefore / so]` [Result]

Let's look at some daily examples:

```cantonese
因為[jan1wai6|because] 佢[keoi5|he / she / it] 琴日[kam4jat6|yesterday (variant)] 唔開心[m4hoi1sam1|sad / unhappy]， 所以[so2ji5|therefore / so] 去[heoi3|to go] 咗[zo2|verbal aspect suffix indicating completed action (perfective aspect)] 玩[waan2|to play / have fun / enjoy]。
===
Because she was sad yesterday, therefore she went to have fun.
```

Another example:

```cantonese
因為[jan1wai6|because] 我[ngo5|I / me] 唔[m4|not / no (negative prefix)] 想[soeng2|to want to / would like to / think] 返工[faan1gung1|to go to work / be at work]， 所以[so2ji5|therefore / so] 打算[daa2syun3|to plan / intend / plan] 放假[fong3gaa3|to have a holiday / day off]。
===
Because I don't want to go to work, I plan to take a holiday.
```

## 2. Concession & Contrast: `雖然[seoi1jin4|although / even though]` ... `但係[daan6hai6|but / however]`

When you want to contrast two ideas ("although A, but B"), you use
`雖然[seoi1jin4|although / even though]` ... `但係[daan6hai6|but / however]`.
Similar to the cause-and-effect pair, Cantonese speakers frequently use both
parts in the same sentence to frame the contrast clearly.

Structure:

- `雖然[seoi1jin4|although / even though]` [Concession],
  `但係[daan6hai6|but / however]` [Contrast/Result]

Let's look at a daily example:

```cantonese
雖然[seoi1jin4|although / even though] 呢度[ni1dou6|here] 啲[di1|some / a little / plural or possessive particle] 嘢食[je5sik6|snacks / food / things to eat] 好[hou2|good / fine / very / quite] 靚[leng3|pretty / beautiful / good-looking]， 但係[daan6hai6|but / however] 真係[zan1hai6|really / truly] 好[hou2|good / fine / very / quite] 貴[gwai3|expensive] 囉[lo1|sentence-final particle showing obviousness, resignation, or 'of course']！
===
Although the food here is very beautiful, it is really expensive, obviously!
```

Another example:

```cantonese
雖然[seoi1jin4|although / even though] 佢[keoi5|he / she / it] 炒[caau2|to stir-fry / speculate / fire] 咗[zo2|verbal aspect suffix indicating completed action (perfective aspect)] 魷魚[jau4jyu2|squid]， 但係[daan6hai6|but / however] 佢[keoi5|he / she / it] 都[dou1|also / both / all] 好[hou2|good / fine / very / quite] 開心[hoi1sam1|happy / glad / cheerful] 呀[aa3|sentence-final particle softening statements, making questions friendly]。
===
Although she got fired, she is still very happy.
```

## 3. Incremental Addition: `唔單止[m4daan1zi2|not only]` ... `仲[zung6|still / yet]`

To add emphasis by listing multiple facts ("not only A, but also B"), Cantonese
uses `唔單止[m4daan1zi2|not only]` paired with `仲[zung6|still / yet]`. This
construction builds narrative momentum, making your description sound highly
engaging and expressive.

Structure:

- `唔單止[m4daan1zi2|not only]` [Fact A], `仲[zung6|still / yet]` [Fact B]

Let's look at an example:

```cantonese
佢[keoi5|he / she / it] 唔單止[m4daan1zi2|not only] 有錢[jau5cin2|rich / wealthy / have money]， 仲[zung6|still / yet] 好[hou2|good / fine / very / quite] 識[sik1|to know / know how to / be familiar with] 玩[waan2|to play / have fun / enjoy] 添[tim1|particle indicating in addition / as well / furthermore]！
===
Not only is he rich, he also really knows how to have fun!
```

Another example:

```cantonese
我[ngo5|I / me] 唔單止[m4daan1zi2|not only] 想[soeng2|to want to / would like to / think] 去[heoi3|to go] 旅行[leoi5hang4|to travel]， 仲[zung6|still / yet] 想[soeng2|to want to / would like to / think] 買[maai5|to buy] 書[syu1|book] 添[tim1|particle indicating in addition / as well / furthermore]。
===
Not only do I want to travel, but I also want to buy books as well.
```

## 4. Extreme Emphasizers & Transitions: `甚至[sam6zi3|even / so much so that]`, `既然[gei3jin4|since / given that]`, `反而[faan2ji4|on the contrary / instead]`

To elevate your narrative fluency to an advanced level, you must master
transitional and logical words that highlight extreme circumstances, logical
consequences, and unexpected outcomes:

- **Extreme Emphasizer**: `甚至[sam6zi3|even / so much so that]` is used to
  introduce an extreme case or build up to a surprising point.
- **Logical Consequence**: `既然[gei3jin4|since / given that]` establishes a
  premise that justifies a subsequent action ("since it is already the case
  that...").
- **Unexpected Contrast**: `反而[faan2ji4|on the contrary / instead]` highlights
  a result that is the opposite of what was expected.

Let's see how each is used:

### 1. Extreme Emphasizer: `甚至[sam6zi3|even / so much so that]`

```cantonese
佢[keoi5|he / she / it] 好[hou2|good / fine / very / quite] 唔開心[m4hoi1sam1|sad / unhappy]， 甚至[sam6zi3|even / so much so that] 喊[haam3|to cry / weep] 咗[zo2|verbal aspect suffix indicating completed action (perfective aspect)] 呀[aa3|sentence-final particle softening statements, making questions friendly]！
===
She was very sad, she even cried!
```

### 2. Logical Consequence: `既然[gei3jin4|since / given that]`

```cantonese
既然[gei3jin4|since / given that] 你[nei5|you] 唔[m4|not / no (negative prefix)] 想[soeng2|to want to / would like to / think] 返工[faan1gung1|to go to work / be at work]， 噉[gam2|then / in that case / so] 就[zau6|then / right away / immediately] 放假[fong3gaa3|to have a holiday / day off] 啦[laa1|sentence-final particle suggesting, requesting, or encouraging action]！
===
Since you don't want to go to work, then in that case just take a holiday!
```

### 3. Unexpected Contrast: `反而[faan2ji4|on the contrary / instead]`

```cantonese
我[ngo5|I / me] 原本[jyun4bun2|originally / original] 諗住[nam2zyu6|to intend / plan / think of] 去[heoi3|to go] 返工[faan1gung1|to go to work / be at work]， 佢[keoi5|he / she / it] 反而[faan2ji4|on the contrary / instead] 叫[giu3|to be called / to call] 我[ngo5|I / me] 去[heoi3|to go] 玩[waan2|to play / have fun / enjoy]。
===
I originally intended to go to work, but he instead told me to go have fun.
```

## 5. Situational Dialogue: Sau-han's Big Exploits

Wing-kit (A) meets Sau-han (B) at a local cafe during working hours. He is
surprised to see her slacking off on a weekday.

```dialog
A: 雖然[seoi1jin4|although / even though] 今日[gam1jat6|today] 唔[m4|not / no (negative prefix)] 係[hai6|to be] 星期六[sing1kei4luk6|Saturday]， 但係[daan6hai6|but / however] 你[nei5|you] 都[dou1|also / both / all] 唔[m4|not / no (negative prefix)] 返工[faan1gung1|to go to work / be at work] 嘅[ge3|possessive particle / nominalizing particle / final assertive particle]？ 點解[dim2gaai2|why / how come] 你[nei5|you] 喺[hai2|at / in / on (locative preposition)] 呢度[ni1dou6|here] hea[hea1|to chill / hang out / slack off / procrastinate] 呀[aa3|sentence-final particle softening statements, making questions friendly]？
   === Although today is not Saturday, you are still not working? Why are you chilling here?
B: 因為[jan1wai6|because] 我[ngo5|I / me] 公司[gung1si1|company / office] 炒[caau2|to stir-fry / speculate / fire] 咗[zo2|verbal aspect suffix indicating completed action (perfective aspect)] 我[ngo5|I / me] 魷魚[jau4jyu2|squid] 囉[lo1|sentence-final particle showing obviousness, resignation, or 'of course']！
   === Because my company fired me yesterday, obviously!
A: 吓[haa2|sentence-final particle expressing surprise, disbelief, or seeking quick confirmation]？！ 炒魷魚[caau2jau4jyu2|to get fired / lay off / fire someone] 呀[aa3|sentence-final particle softening statements, making questions friendly]？ 你[nei5|you] 原本[jyun4bun2|originally / original] 唔開心[m4hoi1sam1|sad / unhappy] 諗住[nam2zyu6|to intend / plan / think of] 喊[haam3|to cry / weep] 呀[aa3|sentence-final particle softening statements, making questions friendly]？
   === What?! Fired? Were you originally sad and planning to cry?
B: 原本[jyun4bun2|originally / original] 係[hai6|to be] 有[jau5|to have / there is] 啲[di1|some / a little / plural or possessive particle] 唔開心[m4hoi1sam1|sad / unhappy] 嘅[ge3|possessive particle / nominalizing particle / final assertive particle]。 但係[daan6hai6|but / however] 我[ngo5|I / me] 唔單止[m4daan1zi2|not only] 冇[mou5|not to have / without / there is not] 喊[haam3|to cry / weep]， 反而[faan2ji4|on the contrary / instead] 好[hou2|good / fine / very / quite] 開心[hoi1sam1|happy / glad / cheerful] 添[tim1|particle indicating in addition / as well / furthermore]！
   === Originally I was indeed a bit sad. But not only did I not cry, on the contrary, I am very happy!
A: 點解[dim2gaai2|why / how come] 呀[aa3|sentence-final particle softening statements, making questions friendly]？
   === Why?
B: 既然[gei3jin4|since / given that] 我[ngo5|I / me] 唔[m4|not / no (negative prefix)] 使[sai2|to need / use] 返工[faan1gung1|to go to work / be at work]， 噉[gam2|then / in that case / so] 我[ngo5|I / me] 就[zau6|then / right away / immediately] 可以[ho2ji5|can / may / possible] 去[heoi3|to go] 旅行[leoi5hang4|to travel] 囉[lo1|sentence-final particle showing obviousness, resignation, or 'of course']！ 我[ngo5|I / me] 甚至[sam6zi3|even / so much so that] 諗住[nam2zyu6|to intend / plan / think of] 去[heoi3|to go] 香港[hoeng1gong2|Hong Kong] 玩[waan2|to play / have fun / enjoy] 兩[loeng5|two / pair (used with classifiers)] 個[go3|general measure word / individual / unit] 星期[sing1kei4|week] 添[tim1|particle indicating in addition / as well / furthermore]！
   === Since I don't have to work, then I can go travel, obviously! I even intend to go to Hong Kong to play for two weeks!
A: 哇[waa1|wow / whoa]！ 你[nei5|you] 唔單止[m4daan1zi2|not only] 好似[hou2ci5|seem / seem like / as if] 有錢[jau5cin2|rich / wealthy / have money] 咗[zo2|verbal aspect suffix indicating completed action (perfective aspect)]， 仲[zung6|still / yet] 好[hou2|good / fine / very / quite] 識[sik1|to know / know how to / be familiar with] hea[hea1|to chill / hang out / slack off / procrastinate] 添[tim1|particle indicating in addition / as well / furthermore]！
   === Wow! Not only do you seem to have become rich, but you also really know how to chill!
```

## 6. Exercises

Test your understanding of advanced Cantonese connectives and narrative flow.

```exercise
question: |
  Translate the following sentence into Cantonese using correct semantic annotations:
  "Although it is raining, I still want to go swimming."
  (Hint: Use seoi1jin4 for "although", daan6hai6 for "but", dou1 for "still/also", and jau4seoi2 for "to swim")
answer: 雖然[seoi1jin4|although / even though] 落雨[lok6jyu5|to rain]， 但係[daan6hai6|but / however] 我[ngo5|I / me] 都[dou1|also / both / all] 想[soeng2|to want to / would like to / think] 去[heoi3|to go] 游水[jau4seoi2|to swim]。
explanation: |
  The concession pattern is `雖然[seoi1jin4|although / even though] ... 但係[daan6hai6|but / however]`. `落雨[lok6jyu5|to rain]` is "to rain", `我[ngo5|I / me]` is "I", `都[dou1|also / both / all]` is "also / both / all", `想[soeng2|to want to / would like to / think]` is "want to", `去[heoi3|to go]` is "go", and `游水[jau4seoi2|to swim]` is "to swim".
```
