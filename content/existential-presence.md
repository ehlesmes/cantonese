In this lesson, we will learn how to describe where objects and places are in
Cantonese, focusing on stating presence and pinpointing locations.

Let's dive in!

---

## 1. Stating Presence: Existential `有[jau5|to have / there is]` and `冇[mou5|to not have]`

In Cantonese, the verbs `有[jau5|to have / there is]` and `冇[mou5|to not have]`
serve a dual purpose. They express personal possession (e.g., "I have a phone")
and existential presence (e.g., "There is a phone here").

### Existential Sentence Pattern

To state that something exists in a specific place, Cantonese uses the following
structure:

> **Formula:** [Location] + `有[jau5|to have / there is]` /
> `冇[mou5|to not have]` + [Noun]

This is equivalent to the English "There is/are..." or "There is/are no...".
Unlike English, which uses "there is" as a dummy subject, Cantonese anchors the
sentence directly to the physical location:

```cantonese
呢度[ni1dou6|here] 有[jau5|to have / there is] 一[jat1|one] 隻[zek3|classifier for animals] 貓[maau1|cat] 呀[aa3|sentence-final particle softening statements, making questions friendly]。
===
There is a cat here.
```

```cantonese
嗰度[go2dou6|there] 冇[mou5|to not have] 廁所[ci3so2|toilet] 呀[aa3|sentence-final particle softening statements, making questions friendly]。
===
There is no restroom there.
```

### Asking Existential Questions (A-not-A Form)

To ask whether something exists in a place, we combine
`有[jau5|to have / there is]` and `冇[mou5|to not have]` into the A-not-A
question form. In colloquial Cantonese, we use the spoken expression
`有冇[jau5mou5|do you have?]`:

```cantonese
呢度[ni1dou6|here] 有冇[jau5mou5|do you have?] 電腦[din6nou5|computer] 呀[aa3|sentence-final particle softening statements, making questions friendly]？
===
Is there a computer here?
```

You can answer simply with `有[jau5|to have / there is]` (yes, there is) or
`冇[mou5|to not have]` (no, there isn't).

## 2. Pinpointing Locations: Preposition `喺[hai2|at / in / on]`

While `有[jau5|to have / there is]` focuses on the _presence_ of an object in a
space, the preposition `喺[hai2|at / in / on]` focuses on the _location_ of a
specific subject.

In Mandarin, the equivalent word is _zài_, but in colloquial Cantonese, you must
always use `喺[hai2|at / in / on]`.

### Location Sentence Pattern

To state where a specific subject is located, use this structure:

> **Formula:** [Subject] + `喺[hai2|at / in / on]` + [Location]

```cantonese
我[ngo5|I] 喺[hai2|at / in / on] 公司[gung1si1|company] 呀[aa3|sentence-final particle softening statements, making questions friendly]。
===
I am at the office.
```

```cantonese
佢[keoi5|he / she / it] 喺[hai2|at / in / on] 學校[hok6haau6|school] 呀[aa3|sentence-final particle softening statements, making questions friendly]。
===
She is at school.
```

### Asking "Where?" using `邊度[bin1dou6|where]`

To ask where someone or something is, replace the location with the question
pronoun `邊度[bin1dou6|where]`:

```cantonese
你[nei5|you] 喺[hai2|at / in / on] 邊度[bin1dou6|where] 呀[aa3|sentence-final particle softening statements, making questions friendly]？
===
Where are you?
```

```cantonese
銀包[ngan4baau1|wallet] 喺[hai2|at / in / on] 邊度[bin1dou6|where] 呀[aa3|sentence-final particle softening statements, making questions friendly]？
===
Where is the wallet?
```

## 3. Conversational Dialogue

Below is a simple dialogue where A is looking for their keys and B indicates
where they are.

```dialog
A: 唔該[m4goi1|thank you / please]，你[nei5|you] 有冇[jau5mou5|do you have?] 見[gin3|to see / meet] 到[dou2|successfully do (verb complement)] 我[ngo5|I] 個[go3|general classifier] 銀包[ngan4baau1|wallet] 呀[aa3|sentence-final particle softening statements, making questions friendly]？
   === Excuse me, have you seen my wallet?
B: 你[nei5|you] 個[go3|general classifier] 銀包[ngan4baau1|wallet] 喺[hai2|at / in / on] 呢度[ni1dou6|here] 呀[aa3|sentence-final particle softening statements, making questions friendly]。
   === Your wallet is here.
A: 喺[hai2|at / in / on] 呢度[ni1dou6|here] 呀[aa3|sentence-final particle softening statements, making questions friendly]？ 噉[gam2|like this / then] 我[ngo5|I] 條[tiu4|classifier for long, thin objects] 鎖匙[so2si4|key] 呢[ne1|sentence-final particle for queries]？ 喺[hai2|at / in / on] 邊度[bin1dou6|where] 呀[aa3|sentence-final particle softening statements, making questions friendly]？
   === It's here? Then what about my keys? Where are they?
B: 鎖匙[so2si4|key] 喺[hai2|at / in / on] 廚房[cyu4fong2|kitchen] 呀[aa3|sentence-final particle softening statements, making questions friendly]。
   === The keys are in the kitchen.
A: 廚房[cyu4fong2|kitchen] 喺[hai2|at / in / on] 邊度[bin1dou6|where] 呀[aa3|sentence-final particle softening statements, making questions friendly]？
   === Where is the kitchen?
B: 喺[hai2|at / in / on] 嗰度[go2dou6|there] 呀[aa3|sentence-final particle softening statements, making questions friendly]。
   === It is there.
A: 搞掂[gaau2dim6|done]！ 搵[wan2|to search / find] 到[dou2|successfully do (verb complement)] 啦[laa3|sentence-final particle for change of state]。 拜拜[baai1baai3|bye-bye]！
   === Got it! Found them. Bye-bye!
B: 拜拜[baai1baai3|bye-bye]！
   === Bye-bye!
```
