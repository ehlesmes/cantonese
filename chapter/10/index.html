Chapter 10

Hypotheticals, Conditionals & Future Planning

Master conditional logic in spoken Cantonese using jyu4gwo2... zau6. Express hypothetical assumptions using gaa2si2, formulate future plans using daa2syun3 and hopes using hei1mong6, and explore local humor like faat3mung6.

Welcome to Chapter 10! In this chapter, we will expand our grammatical toolkit to express logical relationships, hypothetical situations, plans, and aspirations.

First, we will learn how to construct standard "if... then..." conditional sentences using 如果jyu4gwo2
if and 就zau6
then / right away / immediately.

Second, we will explore hypothetical conditions using 假使gaa2si2
if / in case / supposing, which allows you to paint "what if" scenarios.

Third, we will master how to talk about our future intentions and dreams using 打算daa2syun3
to plan / intend / plan and 希望hei1mong6
to hope / wish / hope.

Finally, we will study the authentic local expression 發夢faat3mung6
to dream / daydream / dream and see how to use it to inject humor and native flavor into your conversations.

1. Standard Conditionals: If... Then...

In Cantonese, the most common way to form a conditional sentence ("If A, then B") is by placing 如果jyu4gwo2
if at the start of the first clause, and placing 就zau6
then / right away / immediately right before the verb in the second clause:

Let's look at some daily examples:

1. Weather and Plans:

to go 游水jau4seoi2
to swim 喇laa3

If it rains tomorrow, then I won't go swimming.

2. Hypothetical Possibilities: Supposing...

When you want to describe a purely hypothetical or highly speculative scenario ("supposing that" or "what if"), Cantonese speakers use 假使gaa2si2
if / in case / supposing. Structurally, it functions exactly like 如果jyu4gwo2
if, but it carries a more imaginative or dramatic nuance.

1. Imagining Wealth:

then / right away / immediately 去heoi3
to go 香港hoeng1gong2
Hong Kong 玩waan2

3. Planning & Hopes: Concrete vs. Aspirational

When discussing the future, Cantonese distinguishes between concrete plans (打算daa2syun3
to plan / intend / plan) and emotional aspirations or wishes (希望hei1mong6
to hope / wish / hope).

To describe when these actions will happen, you can use time-related terms like 第日dai6jat6
another day / some day in the future (some day / in the future) or 遲啲ci4di1
later / later on (later on).

Which word is the most appropriate to describe a purely hypothetical or speculative situation (equivalent to "supposing that")?

if
B) 就zau6
then / right away / immediately

if / in case / supposing

Reveal Answer & Explanation
Answer: C

While both 如果jyu4gwo2
