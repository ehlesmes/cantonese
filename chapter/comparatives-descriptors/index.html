Chapter 10

Comparatives & Complex Descriptors

Master relative clauses and noun modifiers in Cantonese using the linking particle ge3. Learn how to make relative comparisons using the suffix di1 and form direct A-over-B comparative sentences using the marker gwo3. Explore superlatives with zeoi3.

In this chapter, we will learn how to describe things in vivid detail and compare them like a native speaker.

Describing and comparing things is a core part of daily conversation. In Cantonese, instead of using a rigid set of prefixes and suffixes like "more," "less," "-er," or "-est," we use dynamic structures involving a few versatile particles: 嘅ge3
possessive particle / nominalizing particle / final assertive particle, 啲di1
a bit / some / comparative suffix, 過gwo3
verbal aspect suffix indicating past experience / 'have done before', and 最zeoi3
most / superlative prefix.

We will learn how to link descriptions to objects, build complex relative clauses (like "the shirt that I bought yesterday"), and express comparative sentences (like "this pair of shoes is cheaper than that one").

Let's dive in!

2. Noun Modification & Complex Descriptions: 嘅ge3
possessive particle / nominalizing particle / final assertive particle

The particle 嘅ge3
possessive particle / nominalizing particle / final assertive particle is one of the most frequently used words in Cantonese. We have already seen it as a possessive marker (similar to English 's). Now, we will see how it works as a general noun modifier and a relative clause linker.

1. Linking Adjectives to Nouns

When you want to describe a noun with a multi-syllable adjective or emphasize an attribute, you link them using 嘅ge3
possessive particle / nominalizing particle / final assertive particle:

  • 靚leng3
    pretty / beautiful / handsome / high quality     嘅ge3
    possessive particle / nominalizing particle / final assertive particle     衫saam1
    clothes / clothing / shirt     — pretty clothes / pretty shirt
  • 貴gwai3
    expensive     嘅ge3
    possessive particle / nominalizing particle / final assertive particle     鞋haai4
    shoes     — expensive shoes
  • 平peng4
    cheap / inexpensive     嘅ge3
    possessive particle / nominalizing particle / final assertive particle     電腦din6nou5
    computer     — cheap computer

3. The Comparative Suffix: 啲di1
a bit / some / comparative suffix

To express that something is "more" [adjective], or has the suffix "-er" (e.g., "cheaper", "taller", "bigger"), spoken Cantonese attaches 啲di1
a bit / some / comparative suffix directly after the adjective.

  • 平peng4
    cheap / inexpensive     啲di1

  • 高gou1

  • 矮ngai2
    short (in height)     啲di1
    a bit / some / comparative suffix     — shorter / a bit shorter
  • 大daai6

    a bit / some / comparative suffix     — bigger / a bit bigger

5. Equality & Negated Comparisons: 同tung4
